# Real-Time-Artistic-Style-Transfer-with-GPU-Acceleration
This project implements real-time artistic style transfer using PyTorch and CUDA. It allows users to apply artistic styles (like those of famous paintings) to live webcam video using a neural network accelerated by GPU.

## Features
- Neural style transfer with a feedforward TransformerNet
- Real-time webcam style transformation
- GPU acceleration with CUDA (PyTorch backend)
